Basics

Probability

Definition: A number between 0 and 1 (inclusive) describing the “magnitude of chance” associated with making a particular observation or statement. Often expressed as a fraction.

Example: Rolling a 5 or 6 on a fair die: Pr(A) = 1/6 + 1/6 = 1/3.

Event

Definition: A specific outcome that can occur. Its chance is written Pr(A). Pr(A) = 0 means A cannot occur; Pr(A) = 1 means A occurs with certainty.

Example: A = “you roll a 4 or more”, so Pr(A) = 1/2.

Frequentist (classical) probability

Definition: The relative frequency with which an event occurs over many identical, objective trials. The default interpretation of probability.

Example: Each side of a fair die has probability 1/6 in any given roll.

Bayesian probability

Definition: A probability that uses prior knowledge or subjective belief to inform the calculation, rather than an impartial reproducible experiment.

Example: “I think there’s a 0.5 chance my partner is angry that I’m late.”

Combining events

Conditional probability, Pr(A|B)

Definition: The probability that A occurs, given that B has already occurred. In general Pr(A|B) ≠ Pr(B|A).

Example: Pr(4 or more | even number) = 2/3, since the evens are 2, 4, 6.

Independent vs. dependent events

Definition: Independent if Pr(A|B) = Pr(A). Dependent if Pr(A|B) ≠ Pr(A). For independent events, Pr(A∩B) = Pr(A) × Pr(B).

Example: Pr(A|B) = 2/3 ≠ Pr(A) = 1/2, so the two die events are dependent.

Intersection, Pr(A ∩ B)

Definition: The probability that both A and B occur simultaneously. Pr(A∩B) = Pr(A|B) × Pr(B) = Pr(B|A) × Pr(A).

Example: Even and 4 or more: 2/3 × 1/2 = 1/3.

Mutually exclusive events

Definition: Events that cannot occur simultaneously: Pr(A∩B) = 0. Their union simplifies to Pr(A∪B) = Pr(A) + Pr(B).

Example: On one die roll, “roll a 1” and “roll a 6” are mutually exclusive.

Union, Pr(A ∪ B)

Definition: The probability that A or B occurs. Pr(A∪B) = Pr(A) + Pr(B) − Pr(A∩B). The intersection is subtracted so it isn’t counted twice.

Example: Even or 4 or more: 1/2 + 1/2 − 1/3 = 2/3.

Complement, Pr(Ā)

Definition: The probability that A does not occur: Pr(Ā) = 1 − Pr(A).

Example: Not rolling 4 or more: 1 − 1/2 = 1/2 (rolling 1, 2 or 3).

Random variables

Random variable

Definition: A variable whose specific outcomes arise by chance or through a random (stochastic) mechanism. Considered before an observation has been made.

Example: Y = result of a die roll; W = tomorrow’s maximum temperature.

Realization

Definition: An actual observed value of a random variable, once an observation has been made.

Example: Y is the random variable; Y = 5 is a realization.

Probability distribution

Definition: The function that defines the probabilities associated with the possible values of a random variable. A mass function if discrete, a density function if continuous.

Example: Table 15-1 gives the distribution for the casino game.

Discrete

Discrete random variable & probability mass function

Definition: Realizations take only certain precise values. The probability mass function gives the probability of each outcome; each lies in [0, 1] and all must sum to exactly 1.

Example: Casino game: −$4 (0.32), $0 (0.48), $1 (0.15), $8 (0.05).

Cumulative probability

Definition: Pr(X ≤ x): the probability of observing a value less than or equal to x. For discrete variables, sum the mass function up to and including x (cumsum() in R).

Example: Pr(X = 0) = 0.48, but Pr(X ≤ 0) = 0.32 + 0.48 = 0.80.

Mean (expected value) of a discrete random variable

Definition: The average outcome expected over many realizations: μ = E[X] = Σ xᵢ × Pr(X = xᵢ). Multiply each outcome by its probability and sum.

Example: Casino game: E[X] = −0.73, an average loss of $0.73 per turn.

Variance of a random variable

Definition: Quantifies variability in the possible realizations: σ² = Var[X] = Σ (xᵢ − μ)² × Pr(X = xᵢ), equivalently E[X²] − μ². The standard deviation is its square root.

Example: Casino game: Var = 7.9371, SD ≈ 2.82.

Continuous

Continuous random variable

Definition: Has infinitely many possible realizations, so probabilities are assigned to intervals, not single values. Pr(W = w) = 0 for any specific w, so < and ≤ give the same answer.

Example: Pr(W ≤ 55.2) is valid; Pr(W = 55.2) is not a meaningful question.

Probability density function (PDF)

Definition: The distribution of a continuous random variable. It must satisfy f(w) ≥ 0 everywhere, and the total area underneath must equal 1. Probabilities are areas under the curve.

Example: Picnic temperature: triangle with base 50, height 0.04; area = ½ × 50 × 0.04 = 1.

Shape

Symmetry and skew

Definition: Symmetric: equally reflected about a center line, so mean = median. Skew (if asymmetric): the direction of the longer tail. Right/positive skew has a longer right tail; left/negative skew a longer left tail.

Example: The casino mass function has mild right skew; the picnic density is perfectly symmetric.

Modality (unimodal, bimodal, trimodal)

Definition: The number of easily identifiable peaks in a distribution. Unimodal, bimodal and trimodal mean one, two and three peaks respectively.

Example: Both the casino and picnic distributions are unimodal.
