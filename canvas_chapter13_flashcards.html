13.1 Raw data

Statistics

Definition: The practice of turning data into information to identify trends and understand features of populations.

Example: In R, raw data are often stored in a data frame, possibly read in from an external file.

Variable

Definition: A characteristic of an individual in a population, whose value can differ between entities within that population.

Example: In mydata: age, sex and humor level are the variables.

Numeric-continuous variable

Definition: Observations are recorded as numbers that can take any value in some interval, to any number of decimal places.

Example: Rainfall of 15 mm or 15.42135 mm both make sense. Chick weight in chickwts.

Numeric-discrete variable

Definition: Naturally numeric, but may take only distinct values (e.g. counts). If the range is restricted, the number of possible values is finite.

Example: Number of heads in 20 coin flips: only integers 0 to 20, never 15.42135.

Categorical variable

Definition: Takes one of a finite number of possibilities, which are not always recorded as numbers. Either nominal or ordinal.

Example: Unlike discrete variables, the values need not be numeric.

Categorical-nominal variable

Definition: A categorical variable whose categories cannot be logically ranked; the order is irrelevant.

Example: Sex (male/female); feed type in chickwts.

Categorical-ordinal variable

Definition: A categorical variable whose categories can be naturally ranked in increasing or decreasing order.

Example: Drug dose: low, medium, high.

Univariate vs. multivariate data

Definition: Univariate: each observation has one component (a single number). Multivariate: more than one component or measurement per observation.

Example: weight is univariate. lat and long together locate a quake (bivariate).

Population vs. sample

Definition: Population: the entire collection of individuals or entities of interest. Sample: a smaller set drawn from it to represent it, since the whole population is rarely accessible.

Example: Population: all US women who own a cat. Sample: a random selection of them.

Parameter vs. statistic

Definition: A parameter is a characteristic of the population (e.g. true mean μ). A statistic is an estimate computed from a sample (e.g. sample mean x̄).

Example: Key difference: does it refer to the sample or the wider population?

13.2.1 Centrality

Mean (arithmetic mean)

Definition: The central “balance point”: x̄ = (x₁ + x₂ + … + xₙ) / n = (1/n) Σ xᵢ.

Example: Data 2, 4.4, 3, 3, 2, 2.2, 2, 4 give 2.825. In R: mean(xdata).

Median

Definition: The “middle magnitude”. Sort the observations; take the middle value if n is odd, or the mean of the two middle values if n is even.

Example: Sorted: 2, 2, 2, 2.2, 3, 3, 4, 4.4 gives (2.2 + 3)/2 = 2.6. In R: median(xdata).

Mode

Definition: The most common observation. Data can have no mode (all unique) or more than one. Used mostly with discrete data, or intervals of continuous data.

Example: The value 2 occurs 3 times, so it is the mode. Find it with table() and xtab[xtab==max(xtab)].

na.rm argument

Definition: Functions like mean, sum, median, max, min and range return NA or NaN if data contain missing values. Setting na.rm=TRUE makes them use only the values present.

Example: mean(c(1,4,NA)) gives NA; with na.rm=TRUE gives 2.5. Use only if you know values are missing.

tapply()

Definition: Computes a statistic for a numeric vector grouped by a categorical variable. Arguments: the numeric vector, INDEX (grouping variable), FUN (function to apply).

Example: tapply(chickwts$weight, INDEX=chickwts$feed, FUN=mean) gives mean weight per feed type.

13.2.2 Counts & proportions

Counts (frequencies) with table()

Definition: The most elementary summary of categorical data: the number of observations falling into each category. Obtained in R with table().

Example: table(chickwts$feed) gives casein 12, horsebean 10, linseed 12, meatmeal 11, soybean 14, sunflower 12.

Proportion

Definition: The fraction of observations in a category, a decimal between 0 and 1: count divided by total sample size. The mean of a logical flag vector gives a proportion.

Example: mean(chickwts$feed=="soybean") = 0.197.

Percentage

Definition: The proportion multiplied by 100, so it lies in [0, 100]. Statisticians usually prefer proportions because of their direct link to probabilities.

Example: Soybean-fed chicks: 0.197 × 100 ≈ 19.7%.

round()

Definition: Rounds numeric output to a given number of decimal places via the digits argument. Default digits=0 rounds to the nearest integer.

Example: round(table(chickwts$feed)/nrow(chickwts), digits=3).

13.2.3 Quantiles

Quantile & percentile

Definition: A value indicating an observation’s rank relative to the others. The pth quantile equals the 100×pth percentile. The median is the 0.5 quantile (50th percentile).

Example: quantile(xdata, prob=0.8) gives 3.6.

Quartiles

Definition: Lower (first) quartile = 0.25 quantile; median = second quartile (0.5); upper (third) quartile = 0.75 quantile; maximum = fourth quartile.

Example: quantile(chickwts$weight, prob=c(0.25,0.75)) gives 204.5 and 323.5.

Five-number summary & summary()

Definition: Minimum, lower quartile, median, upper quartile, maximum (the 0th, 25th, 50th, 75th and 100th percentiles). summary() gives these plus the mean.

Example: summary(xdata): 2.000, 2.000, 2.600, 2.825 (mean), 3.250, 4.400.

Skewed distribution (from summary stats)

Definition: If the max is much further from the upper quartile than the min is from the lower quartile, and the mean exceeds the median, the distribution stretches to the right (positive skew).

Example: Quake magnitudes at depth < 400 km: median 4.6, mean 4.67, max 6.4.

13.2.4 Spread

Sample variance

Definition: Measures spread of observations around the mean (loosely the average squared distance): s² = Σ (xᵢ − x̄)² / (n − 1). R uses the n − 1 divisor, giving an unbiased estimate.

Example: var(xdata) = 0.908 (6.355 / 7).

Standard deviation

Definition: The square root of the variance, s = √s². Interpretable on the same scale as the original observations.

Example: sd(xdata) = 0.953. sd(chickwts$weight) = 78.07 g.

Interquartile range (IQR)

Definition: The width of the middle 50% of the data: IQR = Q(0.75) − Q(0.25). Not computed relative to the mean.

Example: IQR(xdata) = 1.25. Quake magnitudes (depth < 400 km): 4.9 − 4.4 = 0.5.

jitter()

Definition: Randomly alters repeated values slightly before plotting to prevent overplotting, making them easier to see.

Example: points(jitter(c(xdata,ydata)), …) in Figure 13-3. Also: yaxt="n" hides the y-axis; bty="n" removes the box.

13.2.5 Association

Sample covariance

Definition: How much two numeric variables “change together”: rₓᵧ = Σ (xᵢ − x̄)(yᵢ − ȳ) / (n − 1). Positive: y rises as x rises. Negative: y falls as x rises. Zero: no linear relationship. Order doesn’t matter.

Example: cov(xdata, ydata) = 1.479.

Pearson’s correlation coefficient

Definition: Covariance divided by the product of the standard deviations: ρ = rₓᵧ / (sₓ sᵧ). Always between −1 and 1, showing direction and strength of the linear association.

Example: 1.479 / (0.953 × 2.013) = 0.771. cor(xdata, ydata).

Interpreting correlation

Definition: −1 is a perfect negative linear relationship, 0 is none, +1 is perfect positive. Pearson’s only detects straight-line relationships, so a strong non-linear pattern can still give ρ = 0.

Example: Quakes: cor(quakes$mag, quakes$stations) = 0.851, a strong positive association.

Correlation vs. causation

Definition: Correlation does not imply causation. A high correlation between two variables does not mean one causes the other; it only measures association.

Example: Spearman’s and Kendall’s rank coefficients (via cor(..., method=)) don’t require linearity.

13.2.6 Outliers

Outlier

Definition: An observation that doesn’t “fit” with the rest of the data: a noticeably extreme value or anomaly. There is no hard-and-fast numeric rule for what counts as one.

Example: In foo, the value 6.0 sits far from the rest, which are centered around 0.

Natural vs. unnatural outliers

Definition: Natural: a true, accurate observation from the population. Unnatural: “contaminated”, e.g. a data entry error. Unnatural ones are often omitted, but the cause is hard to determine; some researchers analyze both ways.

Example: Always inspect raw data (summaries and plots) before running more rigorous analysis.

Impact of outliers

Definition: A single extreme value can change results a lot, especially for the mean and anything based on it (variance, covariance, correlation).

Example: mean(foo) = 0.49 vs. mean(foo[-10]) = −0.122. cor(bar,baz) = 0.457 vs. 0.890 without the outlier.

Robustness

Definition: A statistic is robust if it is relatively unaffected by outliers. Quantile-based statistics such as the median and IQR are robust; the mean, variance and covariance are sensitive.

Example: Use the median or IQR when extreme values are suspected.
